# 凍結版（`src/frozen/estimator_vN.rs`）の内容と成績

各凍結版が何を入れた版か、凍結時にどの基準へどれだけ勝ち越したか。
CLAUDE.md から切り出した（凍結の手順・共有モデル pin の規約は CLAUDE.md の
`frozen/` 節、設定境界の設計は `docs/frozen-hermetic-boundary.md`）。

**凍結後は編集しない。** 数字は凍結時点の実測で、その後 `SHARED_MODEL_PINS` を
更新すれば v12〜v14 の挙動は動きうる（実例: 2026-08-21 の value NN 再学習。
以後は固定コピーへ向けたので動かない）。ガントレットの値をこの前後でまたいで
比べないこと。

アリーナの**既定の基準は v9 以降**（v6〜v8 は勝率が飽和して検出力がないため
2026-07-31 に既定から除外。明示指定すれば対戦は可能）。

破棄した版: v1（王手放置癖）、v2〜v5（v7 凍結時に全て80%超で上回ったため
2026-07-18 破棄）。成績は git 履歴と `tuning/README.md` に残る。

## 方策ネットの凍結の基準（2026-10-17〜）

Δm の区切り（R-NaD の段階の終わり）で測り、次の2つを満たせば凍結してよい（ユーザー判断）。

1. **直前の版に負け越していない**: 点推定で50%以上、かつ有意な負けがない（200局）
2. **外の相手への勝率を落としていない**: 直前の版とのペア差（`match_seed` でペアにした全相手の合計）が有意にマイナスでない

以前の基準は estimator 時代から引き継いだ「直前の版に有意に勝ち越す」（凍結版を増やすと以後の改善判定が鈍るため厳しくしていた）。
R-NaD は段階ごとに前の版との差が縮み（selfplay 系統で 62.5% → 58.5% → 55.0%）、いずれ凍結できなくなる。
凍結しておけば次の学習方法の対照が凍結版の名前ひとつで取れる（ガントレット・レーティング・別系統との比較）ので緩めた。

ほぼ同じ強さの版が並ぶとガントレット全体の平均で改善が見えにくくなるので、**既定のガントレットに入れるかは凍結とは別に判断する**
（同じ系統で差のない版が3つ以上並んだら古いほうを既定から外す。凍結版の登録は残す）。
