# 凍結版（`src/frozen/estimator_vN.rs`）の内容と成績

各凍結版が何を入れた版か、凍結時にどの基準へどれだけ勝ち越したか。
CLAUDE.md から切り出した（凍結の手順・共有モデル pin の規約は CLAUDE.md の
`frozen/` 節、設定境界の設計は `docs/frozen-hermetic-boundary.md`）。

**凍結後は編集しない。** 数字は凍結時点の実測で、その後 `SHARED_MODEL_PINS` を
更新すれば v12〜v14 の挙動は動きうる（実例: 2026-08-21 の value NN 再学習。
以後は固定コピーへ向けたので動かない）。ガントレットの値をこの前後でまたいで
比べないこと。

アリーナの**既定の基準は v9 以降**（v6〜v8 は勝率が飽和して検出力がないため
2026-07-31 に既定から除外。明示指定すれば対戦は可能）。

破棄した版: v1（王手放置癖）、v2〜v5（v7 凍結時に全て80%超で上回ったため
2026-07-18 破棄）。成績は git 履歴と `tuning/README.md` に残る。
