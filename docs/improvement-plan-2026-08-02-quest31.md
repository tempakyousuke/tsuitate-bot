## 診断

### F1: 幻の詰みボーナスが全候補を圧倒する（m027・m029）

- 27手目 `4一龍` score=88.3 / gain=91.1、29手目 `4一龍` gain=77.3・`5一龍` 28.9。
  2位（銀打ち群 ~6）の**15倍**で、シードに依らず必ず選ばれる
- 出どころは `strategy.rs::evaluate` の粒子上の詰み判定
  `if resolutions == 0 { v += 1000.0 }`。**粒子質量の約8〜9%が「相手玉は
  初期配置近辺（4一/5一）に居て、自分の家の駒で燻されているので4一龍で詰み」と
  信じている**。真の玉は 6二/6三（8手目に動いたが観測ゼロ）
- ユーザー評価は正反対:「相手の金駒に近づくし嬉しいことがない」「6一金・6二玉の
  形は多いので何も取れず王手がかかり龍が取られる」。つまり人間は
  「玉が家にいるなら守り駒も家にいる ＝ 突進した龍はタダで取られる」まで読む。
  bot は詰み分岐の +1000 だけ数え、**同じ粒子群の「外れたら密集地帯で龍を失う」
  分岐が凹んでいない**（recapture_risk はあるが +1000 とスケールが違いすぎる）
- 既知の関連: 玉位置ビリーフが攻め評価の律速（メモリ v2-bottleneck-is-king-belief）。
  ただし king net PROJ は厳密粒子ゼロの決定のみ供給する設計で、ここは
  **厳密粒子が生きていて、その玉位置が観測整合的に誤っている**ケースなので届かない

### F2: 未観測駒への捕獲賭け（m015・m021）

- 15手目 `2二と` gain=6.2 ＝ 2二に居ると信じた**角**への捕獲賭け
  （角は14手目に4四へ逃げたが観測ゼロ）。21手目 `4一と` gain=7.5 ＝ 4一に
  居ると信じた**金**への捕獲賭け（金は直前の20手目に5一へ）
- ユーザーの読み:「角は大体逃げてる」。en_prise_flee（既知の当たりが付いた駒を
  逃がす相手手事前分布）は実装済みだが、**教師のbot自身が42%しか逃げないのが
  信念側の上限**（メモリ enprise-belief-ceiling）。人間は8割逃げるので、
  対人では幻の駒に と金・龍を突っ込む
- capture_bet_var_w（賭け分散ペナルティ）は p_hit(1−p_hit) 型なので
  **信念が自信を持って間違っている（p_hit≈1）と消える**構造的な穴
- なお m015 でユーザーの本命 `P*2b`（同じ賭けを最安の歩で張る。反則になっても
  と金で取れる＝反則の失敗枝が情報として黒字）は候補にすら出ない。これは
  既知バックログ「反則の情報価値」＋持ち駒経済の複合で、F2 とは別工事

### F3: 小粒2件

- m020: `4七歩成` 4.475 vs `4五桂` 4.454 の実質同率で、壁時計ノイズで
  4五桂に流れる（14/20）。「消える手を先に指す」（4七歩成は放置すると
  突いた歩を取られて消える）というオプション失効の概念が無い
- m019: `1一と`（香取り、9/20）は doc 未評価。実在の香なので悪手ではない
  可能性が高いが、ユーザーの評価待ち

## 改善計画（優先順）

### P1: 幻の詰みボーナスの頑健化（対象: m027・m029）

+1000 は「真の局面がこの粒子なら勝ち」として正しいが、較正の悪い信念の
裾（8%）に全評価が乗っ取られるのは意思決定として誤り。方向性は
**詰みボーナスへの証拠ゲート**で、案の優劣は実測で決める:

1. **詰み質量の集中度でスケール**: Σw·1000 をそのまま足すのでなく、
   詰みと信じる質量 q に対して q が閾値未満なら寄与を減衰
   （凸化。q=0.08 の幻詰みは沈み、q>0.5 の本物は残る）
2. **詰み粒子の裏付け検査**: 詰みを主張する粒子の玉位置が
   「最近の観測で裏付けられた玉位置候補」（deduce::opp_king_candidates の
   鋭い側）に入っているかで重みを変える
3. **外れ枝の対称化**: 詰み賭けの外れ分岐（着地マスの recapture_risk）を
   +1000 と同じ王手系スケールで数える

検証: m027/m029 の不合格計 20/20→0 目標。回帰ガードは詰み系
（ansatsu=自分の詰み発見16/20、mate-net-attack、アリーナの詰み終局数
~130-150相場を落とさない）＋ suite 全体。採否はペア3シードアリーナ
（200局×3 vs v13、match_seed=20260801〜03、対照 main 50.2%）。
アリーナの凍結版相手は玉が家に残りがちで幻詰みが「当たる」可能性があるので、
勝率中立でもシナリオ＋詰み指標が守れていれば採用の方針
（メモリ arena-win-rate-cannot-measure-eval）。

### P2: 未観測駒への捕獲賭けの割引（対象: m015・m021）

en_prise_flee の教師較正上限は観測データからは破れないので、信念側でなく
**評価側の割引**で受ける:

- 「当たりが付いたことを相手が知り得る駒」（自分が直前に駒を取ったマスの
  隣接・利き上の敵駒）への捕獲期待値に、逃げられ率の事前確率を掛ける
  （check_king_prior_w=0.73 と同じ「実測事前確率を掛ける」パターン。
  対人実測は8割逃げ、bot教師は42% — まず env ノブで対人値を試す）
- 合わせて外れ枝: 敵陣の守られた地帯（camp_defended_prior は実装済み）への
  高価値駒の突進は、外れ時の取られをもう一段強く敷く

検証: m015/m021 の不合格計、kakutori（王手駒捕獲プローブ 19/20 維持が必須。
王手中は対象外にして干渉を避ける）、tokin-bet。アリーナは
bot 相手だと賭けが当たりやすく微負に出る可能性が高い（drop_hit_evac と同じ
「相手が人間的に振る舞わない」構図）。その場合は既定0の env ノブとして
本番・対人で有効化する。

### P3: バックログ（今回は着手しない）

- **反則の情報価値**（P*2b が浮かぶために必要。human-play-review-2026-07-29 の
  残候補）と**持ち駒経済**（hand_option_w 再挑戦。quest31 系列を回帰ガードに
  加えた scenario-SPSA 第2ラン: 中間点採用・ガード混入の教訓は
  メモリ scenario-spsa-first-run）
- **候補に出ない良い手**: 2一飛成（歩打ち予防）・4二銀打（既知駒群への圧力）・
  3八銀。個別項でなく一般機構（予防・圧力）の評価が要る
- m020 の 4七歩成テンポ（オプション失効）は僅差なので P1/P2 の後に再測定

## P1/P2 の実施結果（2026-08-03）

採用基準は**シナリオ重視・勝率は参考値**（2026-08-02 ユーザー方針）。

**採用: `mate_gate_q0 = 4.0`（幻の詰みゲート、SPSA 57個目）**。
粒子詰み +1000 を質量 q の凸ゲート 1000×q×(q/(q+q0)) に変更。単独20試行で
m027 の 4一龍 20/20→2/20・m029 の龍 19/20→6/20、回帰なし
（m026 4/20・m028 4/20 = ベースライン同等、ansatsu 19〜20/20（ベースライン16/20
から改善）、keima 20/20・dragon-check-drop 20/20・king-evade 20/20・
mate-net-attack/tokin-bet 維持）。

**不採用（実装は残置、既定0）: `king_adj_entry_w`（58個目）**。
玉隣接無支え進入ペナルティ。w=0.6 は m021 の 4一と・m027 の龍を沈める一方、
**m026/m028 の 4七歩成（マージン±0.3）を巻き添え**にして P*2f が 16〜18/20 に
逆流し、quest31 合計不合格計はベースライン 84 → 96 に悪化。
`mover_check_extra` の引き上げ（0.5〜2.0）・`capture_bet_var_w=4` も同型の
モグラ叩きで合計は改善しない（D1/D2 実測）。**「4七歩成 vs 安い探り打ち」の
評価差が razor thin なため、広いスカラー項はどれもここを壊す** —
tune-round3/4 の「スカラー係数調整では届かない」の再現。

**追加採用（2026-08-03 第2弾）: `drop_probe_w = 1.6`（打ちプローブの反則情報価値、
SPSA 59個目）**。ユーザー指摘「2二とが高いだけでなく2二歩打が低いのも問題」を
受けて実装。combine_score の「反則の価値 = 次善手の価値 − 反則コスト」という
仮定の穴を埋める: 打ちの反則枝は占有の確定という情報を買い、自分の利きが既に
当たっていれば次手で回収できる。反則枝の期待回収値 × **占有確率の凸ゲート
（実効 p_occ²）** を combine_score の外側へ加算。
- 凸ゲートが要点: 線形版は占有 8% の 2六への探り（P*2f）が浮いて m026/m028 が
  2/20→18/20 に逆流した。凸形なら「2二=65% は探る・2六=8% は探らない」が
  1本の w で出る
- 実測（20試行）: m015 の P*2b **0/20→20/20（不合格計 20→0）**・
  tokin-bet P*8h 20/20・m026/m028 20/20 維持・m027 不合格 15→9・
  打ち系8件と詰み/王手系の回帰なし。
  quest31 合計不合格計: **84（初回ベースライン）→ 47**

## F3: 2手読みのリスク置き換えが逆向きに働く（2026-08-03 発見、m030f1/f2）

実戦で反則を挟んだ決定点を `fouls=` ディレクティブで再現できるようにした
（30手目 = 反則前 / 1二飛の反則後 / +2一歩打の反則後）ところ、**反則で危険が
判明した後も同じ手（3三角）を 20/20 で選ぶ**ことが分かった。追跡すると:

1. **粒子は正しく更新されている**: 1二飛(5b1b)の反則で「4二/3二/2二のどこかに
   敵駒」が確定し、厳密粒子 1316 → 492（62%棄却）。3三が守られている信念は
   **7.2% → 57.7%**（真実 = 4二の銀が守っている）
2. **静的評価も正しく下がる**: static_gain 6.844 → 5.882
3. **2手読みが下がった分以上を戻す**: depth2 の加算が +0.70 → **+1.85** で、
   最終 gain は 7.547 → **7.734** と逆に上がる

構造上の原因は `gain2 = out.gain + depth2_replace × (out.risk_mean + delta)`
（`depth2_replace` 既定 0.6205）。静的リスク `risk_mean`（＝「利きがあるなら
取り返される」前提の満額）を**丸ごと足し戻して**、応手方策の確率で重み付けた
実測損失 `delta` に置き換える設計だが、相手モデルは取り返しを確率的にしか
選ばないので |delta| < risk_mean になりやすい。結果として
**静的リスクが大きいほど戻し額が大きくなり、危険な捕獲ほど加点される**。
反則で危険度が上がった局面で最も顕著に出る。

副次的な押し上げ: 3三の期待捕獲価値が 5.69 → 6.24 → 6.72 と真実（と金 3.5）を
大きく上回る（粒子が3三に大駒を置いている）。

対応候補（未着手・要アリーナ検証。**全候補に効く中核パラメータ**なので慎重に）:
- 足し戻しを `min(risk_mean, |delta|)` 側に寄せる（危険が減る方向にしか
  置き換えない = 楽観方向の置き換えを禁じる）
- 取り返し確率に下限を敷いて静的リスクと整合させる（捕獲通知でマスが露見する
  ケース = reply_to == to では特に）
- m021（幻の金への 4一と）が同型かどうかを先に確認する

**残る不合格と対応方針**:
- m021（4一と 20/20）— 幻の金への捕獲賭け（移動の手なのでプローブ項の対象外）。
  スカラーでは 4七歩成系との両立不可。scenario-SPSA（GCE）か構造項の領分
- m027（銀打ち 9/20）— 龍暴走は解決済み。残りは hand_option_w の領分
  （w=1.0 で銀打ちは沈む実測あり。既定0はユーザー判断 2026-07-31 のため
  変更には再判断が要る）
- m029（3三銀成 13/20）— 「同じ仕事なら最安の駒で」（観戦局レビュー根②の
  既知ギャップ）。同一マスへの捕獲候補間で高い駒を割り引く新項が必要
