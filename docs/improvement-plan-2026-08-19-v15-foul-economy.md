## 診断: 王手駒仮説の事前は構造的に隣接マスへ偏っている

`CheckSolver` の仮説は（マス, 駒種）の直積で重みが一様 1.0 だった。すると
**P(王手駒のマス) ∝ そのマスから王手になりうる駒種の個数**になる。自玉の隣接マスは
金・と金・成香・成桂・成銀・馬・龍・飛…と 8〜10 通り立つのに対し、離れた飛び駒の
マスは飛/龍の 2 通りしか立たない。

`arena-check-foul01`（玉 3一、真の王手駒は 1一に**打たれた**飛車、K=1）の実測
（`TSUITATE_DEBUG_CHECK=1` に追加した仮説ダンプ）:

```
2aPromotedlance=0.114 3bPawn=0.084 2aTokin=0.047 2bTokin=0.036 3bRook=0.032
2aRook=0.028 1aRook=0.024 1aDragon=0.024 ...
```

2一の 8 仮説が質量 0.33 を占め、真の 1一は 0.048。正解の合駒 `N*2a` の p_legal は
**0.041**、幻の 3二/2二捕獲は removal_term で gain 17 を得て score 4.4 —
**7 連続反則**の内訳はこれで完全に説明できる。

### 読み

1. **仮説のマス単位正規化は駄目**（suite −74・アリーナ −4.8pt）。kakutori も
   10/20 → 7/20 と本命が悪化する。マス一様は「遠い飛び駒」を持ち上げるので、
   玉の逃げ（縦横の王手から抜ける手）が相対的に浮き、正しい隣接捕獲が沈む。
   構造の指摘（隣接が 4〜5 倍重い）は正しいが、**一様に均すのは過剰補正**
2. **反則の証拠を手の種類別にするのも単独では駄目**（suite −63・アリーナ −1.9pt）。
   被王手シナリオの反則は −16% 減るが suite には出ない
3. **併用は suite −46・アリーナ +2.9pt**。被王手シナリオの反則は −31% と大きいが、
   アリーナの反則/局は 6.22 → 6.14 しか動かない。**王手中のバーストは
   反則総量の一部でしかない**（打ちマスが同規模で残る）
4. **効いたのは「反則の値段」側**。反則/局を下げた 2 構成
   （ESCALATION 5.74・反則床 5.88）はどちらも勝率 55.8 / 57.7% で、
   反則/局を上げた HYP_PRIOR（6.37）だけが 48.1% と沈む。
   5点の (反則/局, 勝率) はほぼ単調
5. 反則床は **suite 中立**（956 / 5.231 vs 対照 959 / 5.305）で、
   **foul_limit を含むシナリオが 11 → 3** = 「予算を焼き切る」挙動だけが消える。
   LAST_FOUL_GUARD（残り1回）を 2026-08-10 に採用したときと同じ形

## 現状の結論

- `TSUITATE_CHECK_HYP_PRIOR` / `TSUITATE_CHECK_FOUL_EVIDENCE` /
  `TSUITATE_CHECK_ESCAPE_DECAY` / `TSUITATE_TURN_FOUL_ESCALATION` は
  **すべて既定オフのまま**。機構と診断は残す（env で再試行できる）
- 残り2回/3回の反則床は 200局×3シードのペア計測へ進む（`LAST_FOUL_GUARD_2/_3`）
- 104局（±9.6pt）は ±3pt を判定できない。**単発の 104 局で採否を決めない**
