# NN段階②: 信念ネット（観測履歴 → マスごとの占有分布）

Status: 2026-07-27 着手。**データ基盤とゲート1の計測系まで**。
本番統合（提案分布への prior 注入）はゲートを通ってから。

計画の出典は `docs/improvement-plan-2026-07-25.md` の項目3。段階①（相手手
モデル、estimator_v9）・段階③（粒子上の value ネット、estimator_v10）は
統合済みで、残りが段階②。

## 何を狙うか

粒子の**信念の質**を構造側から改善する。具体的な標的は3つ:

1. **王手駒ビリーフの較正不良**（kakutori の根本原因の残り半分。真の王手駒への
   信念が1.7〜2.7%しかない。`removal_term` は対症療法）
2. **占有マスビリーフ** → 最多の反則カテゴリ「打ちマス」（270件）の削減
3. **反則経済の31ptギャップ**（nofoul オラクル）への初の構造的アプローチ

## 設計方針（過去の失敗を折り込む）

- **評価側の再重み付けチャネルは使わない**。`nn-particle-likelihood` は
  オフライン較正が大幅に改善してもアリーナ中立だった（チャネル飽和）。
  統合先は**提案分布側**（リプレイ・若返り・ソフト救済・枯渇時再生成）
- **ネット出力を raw board sampler にしない**。マスごとの独立占有確率から
  直接サンプルすると駒数・駒種多重集合・二歩・行き所・テンポ・駒間相関が
  全部壊れる。出力はあくまで既存の合法配置・手順生成の**候補順位を動かす
  prior**として使う
- **p_legal への直接供給はしない**。反則マス記憶系4種が全滅済みのチャネル
  （`docs/c8-direct-synthesis.md`）
- 王手中の再重み付けは有害・玉位置の質量を潰すな（ansatsu 回帰）の2教訓は
  設計段階でゲート化する

## 実装（2026-07-27 時点）

### `src/belief_features.rs`

マス1つぶんの35特徴量。**観測履歴（`ObservationLog`）だけ**から作る
（真の局面が混じると学習は良くなるが実戦で使えない）。

- 局面全体の既知量: 基準占有率・相手の盤上駒数の下限・相手が取った枚数・
  進行度・被王手
- マスの静的属性: 相手陣からの深さ・中央度・初期配置の駒種（8種）
- 観測から来る証拠: 相手駒が居たと確定 / 空だと確定（+ それぞれの新しさ）・
  未接触・打ち反則・移動反則・経路反則・自玉の移動反則・自駒の利き数・
  隣接自駒数・自玉からの距離・隣接マスの証拠・直近の被捕獲マスからの距離
- 自玉との幾何: 自駒に遮られず自玉へ利きうる走りのマス（`king_line`）・
  隣接/桂の跳び元（`king_step`）・`deduce::opp_king_candidates`

証拠の採り方は `estimator.rs` の `Guide` と**同じ健全性規約**にした:

- 歩打ちの反則は打ち歩詰めという別の説明があるので占有の証拠にしない
- 王手中の打ち反則も「合駒のはずが別ラインだった」があるので採らない
- 自玉の移動反則だけは経路遮蔽が起きないので理由が「移動先が相手の利き」で
  一意 → 他の移動反則（`to_foul`/`path_foul`）と列を分ける

`BeliefContext::from_log` は 1決定点あたり1回だけ評価すれば足りる
（粒子に依存しない）ので、81マス × 小さな MLP はホットパスに載る。

### `src/truth_replay.rs`

真実（`game:end` の全手順＋反則試行）から**両者の**観測列を再構成して
決定点を1つずつ渡す共通部品。順序・`move_number` 規約・王手宣言の両者通知は
`selfplay.rs` の審判と一致させてある（ここがズレると学習データの観測と
実戦の観測が食い違い、特徴量の意味が変わる）。

### `bin/export_belief_data`

学習データ CSV（1行=1マス、`(game_id, decision_id)` が1決定点、
自駒のマスは除外）。両者ぶんの決定点を出す。`--stride`（既定3）で間引く。

### `bin/belief_probe`

**ゲート1の対照**。現行の粒子フィルタの占有信念を、同じ決定点・同じ
特徴量つきで書き出す（`p_all` / `p_strict` / `n_strict`）。
一様事前との対数損失も並べる。推定器を実戦と同じ順序で逐次 update するので
重い（1局 ≒ 対局1局ぶんの思考）。

### `tsuitate-nn/train_belief.py`, `belief_model.py`

pointwise MLP（35 → 64 → 32 → 占有ロジット + 駒種9クラス）。
対局単位の train/val 分割・正規化統計は学習split のみ（nn-value-phase1 の
行単位分割リークの教訓）。`--baseline-col p_all` で粒子の信念と同じ val 行で
並べられる。

## ゲート（前段で失敗したら実装チャネルを変える）

1. **オフライン較正**: 占有予測が現行粒子（`belief_probe` の `p_all`）を
   上回るか。真の王手駒信念 2.7% → 2桁%
2. **live粒子質量**: 真実マス・真の王手駒への質量が実際の live 粒子群で
   増えたか（オフライン勝利で終わった nn-particle-likelihood の再発防止。
   **ここが動かなければ次段に進まない**）
3. **決定点内の指標**: 候補の p_hit / p_legal の順位変化、打ちマス反則候補が
   上位Nから落ちた率、王手中の正解回避手が top1/top3 に入る率
4. scenario diag（kakutori / ansatsu）+ scenario suite
5. 100局 smoke → 200局フルガントレット。挙動指標は analyze の打ちマス反則
   件数と nofoul ギャップ再測定

**中止基準**: ゲート1〜2で改善が出ない、または最終ゲートでアリーナ中立が
続く場合は統合チャネルを C-8 系へ1回だけ変えて再挑戦、それでも中立なら
段階②を保留して記録する（nn-particle-likelihood と同じ扱い）。

## ゲート1の結果（2026-07-27）: **通過**

アリーナ600局中570局（v10/v11/v12 の自己対局、`match_seed=20260727`）で学習し、
**完全に別の対局**（対人30局・stride 4・33,090マス）で現行の粒子フィルタと
突き合わせた。粒子側は `belief_probe`（思考予算2000ms、実戦と同じ逐次 update）。

| | 対数損失 | Brier | AUC |
| --- | --- | --- | --- |
| 一様事前 | 0.5845 | 0.1981 | 0.567 |
| 現行の粒子フィルタ（p_all） | 0.4615 | 0.1261 | 0.877 |
| **信念ネット** | **0.3653** | **0.1169** | **0.892** |

4シード（0〜3）とも 0.365〜0.369 / AUC 0.890 で安定。

**勝っている場所がはっきり偏っている**:

| 部分集合 | n | 粒子 | ネット |
| --- | --- | --- | --- |
| 厳密粒子ゼロ（ブラインド） | 2,818 | 0.8141 / .721 | **0.3756 / .841** |
| 終盤（相手手数≥40） | 912 | 0.9295 / .677 | **0.4571 / .762** |
| 王手中 | 2,100 | 0.9139 / .761 | **0.4551 / .802** |
| 接触済みマス | 7,699 | 0.3359 / .828 | 0.2592 / .850 |
| 序盤（相手手数<20） | 20,528 | 0.3289 / .925 | 0.3267 / .922（互角） |

粒子が健全な序盤では互角で、**粒子が枯れる場所でだけ大きく勝つ**。
粒子とネットを 50:50 で混ぜると 0.3478 と単独より良いので、両者の信念は
補完的（＝置き換えではなく足し算の関係）。

**ただし計画の標的(a)「王手駒ビリーフ較正」は改善しない**: 真の王手駒マスへの
平均信念は粒子 0.3692 に対しネット 0.3285 とむしろ微減。pointwise ネットは
「今どの駒が王手しているか」という同時制約を表現できないため。ここは
CheckSolver（制約推論）の領分のままで、段階②では埋まらない。

## ゲート2（提案分布への prior 注入）: 初回は全条件で悪化

`sample_opp_move` の提案重み g に `exp(w × (logit_occ[to] − logit_occ[from]))` を
掛ける（打ちは出ていくマスが無いので盤面平均を基準）。重み補正 `ln(p/g)` は
既存のまま払われるので分布は歪まない（`belief_prior_sampling_is_unbiased`）。

チャネルは2つの env に分けた（**どちらも既定0で、0なら prior を計算もしない
＝挙動不変**。凍結版はこの名前を知らないので `-f env=` は候補側にだけ効く）:

- `TSUITATE_BELIEF_LIVE_W` — 毎ターンの制約適用（生存粒子が必ず通る道）
- `TSUITATE_BELIEF_GUIDE_W` — リプレイ・若返り・ソフト救済（再生成の道）

対人15局（263決定点）。**対照は必ず複数 seed 取ること**（下記）:

| 条件 | ブラインド決定点 | p_all 対数損失 | AUC | ブラインド時の p_all |
| --- | --- | --- | --- | --- |
| 対照 seedA | 31 (11.8%) | 0.4796 | 0.871 | 0.7749 |
| 対照 seedB | 36 (13.7%) | 0.4545 | 0.881 | 0.7002 |
| 対照 w≈0（prior だけ計算） | 36 (13.7%) | 0.4622 | 0.875 | 0.6892 |
| live=0.25 | 35 (13.3%) | 0.5166 | 0.868 | 0.8470 |
| live=1 | 58 (22.1%) | 0.5426 | 0.869 | 0.8561 |
| live=3 | 51 (19.4%) | 0.8047 | 0.846 | 1.2651 |
| **guide=0.25** | 38 (14.4%) | **0.4526** | **0.882** | **0.6289** |
| guide=1 | 53 (20.2%) | 0.4955 | 0.875 | 0.6688 |
| 両方=1 | 54 (20.5%) | 0.6358 | 0.859 | 0.9593 |

**最初に対照を1本しか取らずに「全条件で悪化」と判定したのは誤りだった**:
seed を変えるだけで対照が p_all 0.4796↔0.4545・ブラインド率 11.8%↔13.7% 動く。
メモリ `arena-main-control-baseline`（候補の数字は対照ラン無しでは解釈できない）
がそのまま当てはまる。`w≈0`（prior は計算するが効果ゼロ）が seedB とほぼ同じ
なので、**計算コストや RNG 系列の交絡ではない**ことも確認済み。

読み:

- **live チャネルは本当に有害**で、w に対して単調に悪化する（0.25 でも対照割れ）。
  周辺分布で同時分布のサンプラーを操ると、粒子が「平均的な世界」（実在しない
  盤面）へ引っ張られる
- **guide チャネルは弱い重み（0.25）なら有望**。全対照より p_all・AUC とも良く、
  特に**ブラインド時の信念は 0.6289 と対照の 0.6892〜0.7749 より明確に良い**。
  w=1 は強すぎてブラインド率を上げる（＝リプレイが needle を通せなくなる）

ただし8条件から最良を拾っているので、別 seed での再現確認が要る。

### 適用範囲（`TSUITATE_BELIEF_SPAN`）: 理屈と実測が逆だった

ネットの信念は**現在の局面**の周辺分布なのに、リプレイでは過去の相手手すべてに
適用していた。当時その駒が着地したマスは今はもう空いているのが普通なので、
理屈の上では**正しい歴史の手を罰している**はず。末尾の相手決定点だけに
効かせる版（span=1）を作って測ると:

| 条件 | ブラインド | p_all | ブラインド時 p_all |
| --- | --- | --- | --- |
| span=1, w=1 | 12.2% | 0.4983 | 0.8001 |
| span=1, w=0.25 | 12.2% | 0.4925 | 0.6971 |
| **span=全, w=0.25** | 14.4% | **0.4526** | **0.6289** |

- **ブラインド率倍増の原因は確定**: span=1 にすると w=1 でも 20.2% → 12.2% に
  戻る＝「過去の相手手への prior 適用でリプレイが needle を通せなくなる」
- **しかし信念の質は制限なしのほうが良い**。駒はそう遠くへ動かないので現在の
  周辺分布は近い過去とも強く相関しており、**軌跡全体を今の信念へ寄せた粒子の
  ほうが、評価が実際に見る最終配置として正しい**

理屈より実測を採り、既定は「制限なし」（`TSUITATE_BELIEF_SPAN=0`）にした。

### seed 再現（決着）: **ゲート2は中立**

8条件から最良を拾った `guide=0.25` を、対照とペアで seed A/B/C の3組に増やした
（各15局・263決定点）:

| seed | 対照 p_all | guide=0.25 p_all | Δ | 対照ブラインド時 | guide ブラインド時 | Δ |
| --- | --- | --- | --- | --- | --- | --- |
| A | 0.4796 | 0.4526 | **−0.0270** | 0.7749 | 0.6289 | **−0.1460** |
| B | 0.4545 | 0.4554 | +0.0009 | 0.7002 | 0.7531 | +0.0530 |
| C | 0.4380 | 0.4471 | +0.0091 | 0.6352 | 0.6130 | −0.0220 |
| 平均 | 0.4574 | 0.4517 | −0.0057 (SD 0.019) | 0.7034 | 0.6650 | −0.038 (SD 0.102) |

ブラインド率も 12.6% → 12.8% で中立。**seedA の優位は偶然**で、平均の差は
いずれも SD の 1/3 以下。**提案分布チャネルでのゲート2は中立**。

過去の同型の結果（occupies/path_blocks ガイド、反則マス記憶系4種、
nn-particle-likelihood）と同じく、**粒子の提案分布はもう飽和している**という
読みで一貫する。

なお既定（w=0）の挙動不変性はアリーナ20局で確認済み
（vs estimator_v12 で 50.0%、思考時間 1316ms vs 1314ms）。

## 現時点の結論と、次のチャネルの候補

- **ゲート1は決定的に通過**。信念ネットは現行の粒子より当たり、しかも
  **粒子が枯れる場所に勝ちが集中**する
- **ゲート2（提案分布）は中立**。live チャネルは有害、guide チャネルは中立。
  計画の中止基準に従えば、ここで**統合チャネルを1回だけ変える**局面

実測が指している次のチャネルは明確:

**アリーナでは決定点の 29.2% で厳密粒子がゼロ**で、そこの粒子の占有信念は
AUC 0.685（ほぼ無情報）・対数損失 1.0657。ネットは同じ場所で AUC 0.821 /
0.4418。そして v12 で入れた `BLIND_RECAPTURE_W` は、まさにこの
「厳密粒子ゼロの決定では `expected` ごと駒得が消える」欠陥に対する手当てで、
**観測だけで確実に言える1マス（直前に取られたマス）に限定**されている。
信念ネットはそれを**盤面全体へ一般化**したものになる。

チャネルの区別として重要なのは、これは `p_hit` / gain 側であって
**`p_legal` 側ではない**こと（反則マス記憶系4種が全滅したのは p_legal 側）。
また「既存粒子の再重み付け」（nn-particle-likelihood で飽和）でもなく、
「粒子が1つも無いときに信念を供給する」チャネルである。

## ゲート3〜5（ブラインド供給 `TSUITATE_BELIEF_GAIN_W`）

### 初版（凹割引なし・王手中ゲートなし）は明確に負

200局ペア比較（vs v12、`match_seed=20260730`、共通3シャード150局）:
勝率 42.8% vs 対照 47.3%（**3シャードとも対照割れ** −4.3/−4.2/−5.1pt）、
反則/局 6.56 vs 6.56（改善なし）、**平均手数 112.8 vs 104.5・手数上限による
引き分け 5 vs 0**。「投機的な捕獲で手数だけ伸びる」形。
シナリオ `dragon-check-drop` の反則も 12 → 29 と増えた（王手中ゲートの欠落）。

なお w=1 は対局が長くなり、シャード1本がランナー消失で落ちた（1h49m）。

### 修正版（凹割引 + 王手中ゲート）

- 素の `p×stake` は空振り分岐（賭けが外れ、進出駒だけが未知領域に残る側）を
  数えないので、通常経路と同じ `capture_bet_var_w × p(1−p) × 価値` を引く
- 王手中は無効（`value_nn_w` / `mate_*_w` / `capture_bet_var_w` と同じゲート）

200局（vs v12、`match_seed=20260730`）:

| 指標 | 対照 w=0 | **w=0.5** | w=1 |
| --- | --- | --- | --- |
| 勝率 | 48.5% ±6.9 | 48.0% ±6.9 | 44.4% ±6.9 |
| 反則/局 | 6.43 | 6.44 | 6.73 |
| 平均手数 | 106.9 | 107.9 | 110.4 |
| 手数上限（引き分け） | 0 | 0 | 2 |
| **只取られ** | 808 | **748**（−7.4%） | 779 |
| **被詰めろ** | 167 / 67局 | **134 / 60局**（−20%） | 133 / 58局 |
| **王手中の反則** | 548 | **461**（−16%） | 485 |
| 打ちマスに見えない駒 | 499 | 550（+10%） | 564 |
| 王手を解消できない手 | 540 | 457（−15%） | 476 |
| 自ら王手に飛び込んだ | 78 | 75 | 123 |
| 取り返し逃し | 185 | 181 | 179 |
| 駒得収支 | +327 | +245 | +548 |
| p_legal 対数損失 | 0.3383 | 0.3452 | 0.3984 |

シナリオ（w=1・20試行、対照との比較）: `dragon-check-drop` 反則 17（対照12・
初版29 = ゲートは効いたが対照には戻らず）、`kakutori` 反則 11（対照18）、
`recap-dragon` 16/20（対照17）、`kakunari` 0/20（対照0）。

**読み**: w=0.5 は**狙った機構指標（只取られ −7.4%・被詰めろ −20%・王手中の
反則 −16%）が改善する一方、打ちマス反則が +10% で相殺し、反則/局と勝率は完全に
横ばい**。w=1 は明確に負。強さは動かない。

## 結論（2026-07-27）

**段階②は「信念そのものは作れたが、強さには変換できなかった」で保留する**
（nn-particle-likelihood と同じ扱い）。

- ゲート1は決定的に通過した。信念ネットは現行の粒子より当たり、しかも
  **粒子が枯れる場所（アリーナの決定点の29.2%）に勝ちが集中**する
- しかし供給チャネルを2つ試して（提案分布 / ブラインド時の gain）、
  どちらも**勝率は中立**だった。提案分布は中立、gain 供給は機構指標だけ改善
- `king_hole_w` と同じ構図（機構指標は単調に良くなるが勝率は動かない）なので、
  **既定0のままノブを残す**のが前例と整合する

残す資産: `belief_features.rs` / `belief_nn.rs` / `truth_replay.rs` /
`bin/export_belief_data` / `bin/belief_probe` / tsuitate-nn の学習一式。
`belief_probe` は**粒子の信念の質を決定点ごとに測れる初めての道具**なので、
段階②と独立に診断へ使える。
