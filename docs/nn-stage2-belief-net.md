# NN段階②: 信念ネット（観測履歴 → マスごとの占有分布）

Status: 2026-07-27 着手。**データ基盤とゲート1の計測系まで**。
本番統合（提案分布への prior 注入）はゲートを通ってから。

計画の出典は `docs/improvement-plan-2026-07-25.md` の項目3。段階①（相手手
モデル、estimator_v9）・段階③（粒子上の value ネット、estimator_v10）は
統合済みで、残りが段階②。

## 何を狙うか

粒子の**信念の質**を構造側から改善する。具体的な標的は3つ:

1. **王手駒ビリーフの較正不良**（kakutori の根本原因の残り半分。真の王手駒への
   信念が1.7〜2.7%しかない。`removal_term` は対症療法）
2. **占有マスビリーフ** → 最多の反則カテゴリ「打ちマス」（270件）の削減
3. **反則経済の31ptギャップ**（nofoul オラクル）への初の構造的アプローチ

## 設計方針（過去の失敗を折り込む）

- **評価側の再重み付けチャネルは使わない**。`nn-particle-likelihood` は
  オフライン較正が大幅に改善してもアリーナ中立だった（チャネル飽和）。
  統合先は**提案分布側**（リプレイ・若返り・ソフト救済・枯渇時再生成）
- **ネット出力を raw board sampler にしない**。マスごとの独立占有確率から
  直接サンプルすると駒数・駒種多重集合・二歩・行き所・テンポ・駒間相関が
  全部壊れる。出力はあくまで既存の合法配置・手順生成の**候補順位を動かす
  prior**として使う
- **p_legal への直接供給はしない**。反則マス記憶系4種が全滅済みのチャネル
  （`docs/c8-direct-synthesis.md`）
- 王手中の再重み付けは有害・玉位置の質量を潰すな（ansatsu 回帰）の2教訓は
  設計段階でゲート化する

## 実装（2026-07-27 時点）

### `src/belief_features.rs`

マス1つぶんの35特徴量。**観測履歴（`ObservationLog`）だけ**から作る
（真の局面が混じると学習は良くなるが実戦で使えない）。

- 局面全体の既知量: 基準占有率・相手の盤上駒数の下限・相手が取った枚数・
  進行度・被王手
- マスの静的属性: 相手陣からの深さ・中央度・初期配置の駒種（8種）
- 観測から来る証拠: 相手駒が居たと確定 / 空だと確定（+ それぞれの新しさ）・
  未接触・打ち反則・移動反則・経路反則・自玉の移動反則・自駒の利き数・
  隣接自駒数・自玉からの距離・隣接マスの証拠・直近の被捕獲マスからの距離
- 自玉との幾何: 自駒に遮られず自玉へ利きうる走りのマス（`king_line`）・
  隣接/桂の跳び元（`king_step`）・`deduce::opp_king_candidates`

証拠の採り方は `estimator.rs` の `Guide` と**同じ健全性規約**にした:

- 歩打ちの反則は打ち歩詰めという別の説明があるので占有の証拠にしない
- 王手中の打ち反則も「合駒のはずが別ラインだった」があるので採らない
- 自玉の移動反則だけは経路遮蔽が起きないので理由が「移動先が相手の利き」で
  一意 → 他の移動反則（`to_foul`/`path_foul`）と列を分ける

`BeliefContext::from_log` は 1決定点あたり1回だけ評価すれば足りる
（粒子に依存しない）ので、81マス × 小さな MLP はホットパスに載る。

### `src/truth_replay.rs`

真実（`game:end` の全手順＋反則試行）から**両者の**観測列を再構成して
決定点を1つずつ渡す共通部品。順序・`move_number` 規約・王手宣言の両者通知は
`selfplay.rs` の審判と一致させてある（ここがズレると学習データの観測と
実戦の観測が食い違い、特徴量の意味が変わる）。

### `bin/export_belief_data`

学習データ CSV（1行=1マス、`(game_id, decision_id)` が1決定点、
自駒のマスは除外）。両者ぶんの決定点を出す。`--stride`（既定3）で間引く。

### `bin/belief_probe`

**ゲート1の対照**。現行の粒子フィルタの占有信念を、同じ決定点・同じ
特徴量つきで書き出す（`p_all` / `p_strict` / `n_strict`）。
一様事前との対数損失も並べる。推定器を実戦と同じ順序で逐次 update するので
重い（1局 ≒ 対局1局ぶんの思考）。

### `tsuitate-nn/train_belief.py`, `belief_model.py`

pointwise MLP（35 → 64 → 32 → 占有ロジット + 駒種9クラス）。
対局単位の train/val 分割・正規化統計は学習split のみ（nn-value-phase1 の
行単位分割リークの教訓）。`--baseline-col p_all` で粒子の信念と同じ val 行で
並べられる。

## ゲート（前段で失敗したら実装チャネルを変える）

1. **オフライン較正**: 占有予測が現行粒子（`belief_probe` の `p_all`）を
   上回るか。真の王手駒信念 2.7% → 2桁%
2. **live粒子質量**: 真実マス・真の王手駒への質量が実際の live 粒子群で
   増えたか（オフライン勝利で終わった nn-particle-likelihood の再発防止。
   **ここが動かなければ次段に進まない**）
3. **決定点内の指標**: 候補の p_hit / p_legal の順位変化、打ちマス反則候補が
   上位Nから落ちた率、王手中の正解回避手が top1/top3 に入る率
4. scenario diag（kakutori / ansatsu）+ scenario suite
5. 100局 smoke → 200局フルガントレット。挙動指標は analyze の打ちマス反則
   件数と nofoul ギャップ再測定

**中止基準**: ゲート1〜2で改善が出ない、または最終ゲートでアリーナ中立が
続く場合は統合チャネルを C-8 系へ1回だけ変えて再挑戦、それでも中立なら
段階②を保留して記録する（nn-particle-likelihood と同じ扱い）。

## ゲート1の結果（2026-07-27）: **通過**

アリーナ600局中570局（v10/v11/v12 の自己対局、`match_seed=20260727`）で学習し、
**完全に別の対局**（対人30局・stride 4・33,090マス）で現行の粒子フィルタと
突き合わせた。粒子側は `belief_probe`（思考予算2000ms、実戦と同じ逐次 update）。

| | 対数損失 | Brier | AUC |
| --- | --- | --- | --- |
| 一様事前 | 0.5845 | 0.1981 | 0.567 |
| 現行の粒子フィルタ（p_all） | 0.4615 | 0.1261 | 0.877 |
| **信念ネット** | **0.3653** | **0.1169** | **0.892** |

4シード（0〜3）とも 0.365〜0.369 / AUC 0.890 で安定。

**勝っている場所がはっきり偏っている**:

| 部分集合 | n | 粒子 | ネット |
| --- | --- | --- | --- |
| 厳密粒子ゼロ（ブラインド） | 2,818 | 0.8141 / .721 | **0.3756 / .841** |
| 終盤（相手手数≥40） | 912 | 0.9295 / .677 | **0.4571 / .762** |
| 王手中 | 2,100 | 0.9139 / .761 | **0.4551 / .802** |
| 接触済みマス | 7,699 | 0.3359 / .828 | 0.2592 / .850 |
| 序盤（相手手数<20） | 20,528 | 0.3289 / .925 | 0.3267 / .922（互角） |

粒子が健全な序盤では互角で、**粒子が枯れる場所でだけ大きく勝つ**。
粒子とネットを 50:50 で混ぜると 0.3478 と単独より良いので、両者の信念は
補完的（＝置き換えではなく足し算の関係）。

**ただし計画の標的(a)「王手駒ビリーフ較正」は改善しない**: 真の王手駒マスへの
平均信念は粒子 0.3692 に対しネット 0.3285 とむしろ微減。pointwise ネットは
「今どの駒が王手しているか」という同時制約を表現できないため。ここは
CheckSolver（制約推論）の領分のままで、段階②では埋まらない。

## ゲート2（提案分布への prior 注入）: 初回は全条件で悪化

`sample_opp_move` の提案重み g に `exp(w × (logit_occ[to] − logit_occ[from]))` を
掛ける（打ちは出ていくマスが無いので盤面平均を基準）。重み補正 `ln(p/g)` は
既存のまま払われるので分布は歪まない（`belief_prior_sampling_is_unbiased`）。

チャネルは2つの env に分けた（**どちらも既定0で、0なら prior を計算もしない
＝挙動不変**。凍結版はこの名前を知らないので `-f env=` は候補側にだけ効く）:

- `TSUITATE_BELIEF_LIVE_W` — 毎ターンの制約適用（生存粒子が必ず通る道）
- `TSUITATE_BELIEF_GUIDE_W` — リプレイ・若返り・ソフト救済（再生成の道）

対人15局（263決定点）の初回計測:

| 条件 | ブラインド決定点 | p_all 対数損失 | ブラインド時の p_all |
| --- | --- | --- | --- |
| 対照（w=0） | 31 (11.8%) | **0.4796** | 0.7749 |
| live=1 | 58 (22.1%) | 0.5426 | 0.8561 |
| live=3 | 51 (19.4%) | 0.8047 | 1.2651 |
| guide=1 | 53 (20.2%) | 0.4955 | **0.6688** |
| 両方=1 | 54 (20.5%) | 0.6358 | 0.9593 |

- **どの条件もブラインド決定点（厳密粒子ゼロ）が約2倍**になる。粒子の再生成は
  多数の制約という針の穴を通す確率なので、制約に合わせて調律済みの提案分布を
  別の prior で歪めると成功率が素直に落ちる（occupies/path_blocks ガイドや
  反則マス記憶系4種が全滅したのと同じ構図）
- ただし **guide チャネルは「ブラインドになったときの信念の質」は改善**する
  （0.7749 → 0.6688）。狙った効果自体は出ているが、副作用が上回る
- live チャネルは w に対して単調に悪化。**周辺分布で同時分布のサンプラーを
  操ると、粒子が「平均的な世界」（実在しない盤面）へ引っ張られる**

### 切り分けと修正

w=0.25 でも w=3 でもブラインド率がほぼ同じ（19〜22%）で用量依存的でないため、
対照を追加した: `w≈0`（prior は計算するが効果ゼロ = コスト/RNG系列の交絡確認）と
**w=0 で seed だけ変えた対照**（ブラインド率の seed 分散そのもの）。

並行して設計上の欠陥を1つ修正した: ネットの信念は**現在の局面**の周辺分布
なのに、リプレイでは過去の相手手すべてに適用していた。当時その駒が着地した
マスは今はもう空いているのが普通なので、**正しい歴史の手を罰していた**。
末尾の相手決定点だけに効かせるよう変更（`BELIEF_RECENT_DECISIONS`）。

## 計測メモ

### 特徴量の素の信号（対人83局・stride 4・96,910行、2026-07-27）

基準占有率 27.4%。条件付き占有率:

| 特徴量 | 発火率 | P(占有\|発火) |
| --- | --- | --- |
| `drop_foul`（打ち反則） | 0.2% | **62.8%** |
| `init_opp`（初期配置マス） | 30.3% | 62.5% |
| `king_cand` | 51.9% | 39.4% |
| `untouched` | 75.4% | 32.6% |
| `opp_seen` | 5.5% | 29.7% |
| `king_foul` | 0.5% | 22.7% |
| `path_foul` | 0.7% | 16.1% |
| `to_foul` | 0.4% | 13.5% |
| `king_line` | 13.7% | **11.4%** |
| `empty_seen` | 22.3% | **8.0%** |
| `king_step` | 7.8% | **5.1%** |

設計どおり `drop_foul` は直接の占有証拠、`empty_seen` / `king_line` /
`king_step` は強い**負**の証拠として効いている（「そこから王手できる位置に
居るなら今王手されているはず」の対偶）。`opp_seen` が基準占有率とほぼ
同じなのは、相手駒が確認されたマスはその後よく空くため（新しさ列
`opp_seen_rec` のほうが効くはず）。
